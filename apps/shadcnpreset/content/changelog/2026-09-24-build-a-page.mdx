[Build a page](/build) is a full page builder for shadcn/ui. Browse the [shadcncraft](https://shadcncraft.com?atp=shadcnpreset&src=changelog) Pro blocks, add the ones you want, and arrange them right on the page. Every block is built from the components defined by the preset, so switching presets restyles the whole page: colours, radius, fonts and icons.

What's included:

- **157 blocks to build with** — heroes, features, pricing, testimonials, FAQs and more for landing pages; categories, products, cart and checkout for stores; charts, tables and metrics for dashboards; plus headers, sidebars and footers
- **Browse and add** — search the blocks, narrow them by kind, and click a preview to add it to the page
- **Edit on the page** — hover a block to move it up or down or remove it; clear the page and start again, with undo
- **Any preset on top** — shuffle for a random one, pick one you've saved, or save the one on screen
- **Share what you built** — the page lives in its link, so it opens exactly as you left it
- **Get the code** — the blocks are shadcncraft Pro, and one click takes you there

You can also start with AI. Describe a page, like "landing page for a cosy coffee shop" or "dark fintech dashboard for sales teams", and Jev, from [TypeSafe](https://typesafe.ai), drafts it in about half a second: the sections, a design for each, a header and footer, and a preset to dress it in. Then edit it like any other page.

Also new: **Build** is in the main navigation, and **Community** has moved into the **Presets** menu.
