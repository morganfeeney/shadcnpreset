[Build a page](/build) turns a description into a page. Type "landing page for a cosy coffee shop" or "dark fintech dashboard for sales teams" and Jev, from [TypeSafe](https://typesafe.ai), picks the sections, a design for each, a header and footer, and a preset to dress it in. The whole draft arrives in about half a second.

Every block comes from [shadcncraft](https://shadcncraft.com?atp=shadcnpreset&src=changelog) Pro, and the page is built from the components defined by the preset, so switching presets restyles all of it: colours, radius, fonts and icons.

What's included:

- **157 blocks to build with** — heroes, features, pricing, testimonials, FAQs and more for landing pages; categories, products, cart and checkout for stores; charts, tables and metrics for dashboards; plus headers, sidebars and footers
- **Browse and add** — search the blocks, narrow them by kind, and click a preview to add it to the page
- **Edit on the page** — hover a block to move it up or down or remove it; clear the page and start again, with undo
- **Any preset on top** — keep Jev's, shuffle for a random one, pick one you've saved, or save the one on screen
- **Share what you built** — the page lives in its link, so it opens exactly as you left it
- **Get the code** — the blocks are shadcncraft Pro, and one click takes you there

A description is optional: you can start from an empty page and add blocks yourself.

Also new: **Build** is in the main navigation, and **Community** has moved into the **Presets** menu.
