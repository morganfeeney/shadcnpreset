What's included:

- **Get Code on preset pages** — grab commands for installing code using the shadcn CLI or coy theme CSS directly form the preset you are browsing
- **Get Code on preset detail pages** — the sticky controls now open the same New Project, Existing Project, and Theme dialog as Edit
- **Copy the preset code from the preview title** — same one-click copy as the edit page heading
